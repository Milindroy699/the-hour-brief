Telegram (by hand)

Set up automatic Telegram posting
  1. In Telegram, message @BotFather → /newbot → copy the bot token.
  2. Create a channel and add the bot as an administrator that can post messages.
  3. In Vercel → Project → Settings → Environment Variables (Production) add TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID (@yourchannel) and CRON_SECRET (any long random string), then redeploy.
  4. Test without posting: curl -H "Authorization: Bearer $CRON_SECRET" "https://the-hour-brief.vercel.app/api/post-digest?dry=1". Remove ?dry=1 to post for real.

Once set up it posts around 10:00 IST after each edition, once per day, and retries an hour later if the edition wasn’t ready.
